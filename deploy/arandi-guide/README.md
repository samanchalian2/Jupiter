# Jupiter website guide overlay

This is the reviewed Jupiter-guide-only content/component/PDF overlay for
`https://arandi.io/knowledge/jupiter-guide?lang=fa`. It is not another website,
an Arandi database copy, or a replacement application. The owner requested this
refresh in the Jupiter development chat; no other chat was messaged.

The authoritative baseline was recovered from the active Arandi release
`20261012T-articles-guides-hub-r2`. The local legacy WordPress checkout has a
broken old-account worktree pointer and predates the guide; it was not edited,
reset or treated as the production source. Preserve the broader website source
and apply these two source paths only to a compatible checkout:

- `src/content/jupiter-guide.fa.md`: one shared content source for Web and PDF.
- `src/components/jupiter/JupiterGuide.tsx`: corrected personal path, readable
  journey, optional monitoring disclosure, canonical entry-link fallback and
  removal of a hard-coded PDF page count. Existing palette/CSS remains unchanged.
- `public/guides/jupiter-comprehensive-user-guide-fa.pdf`: reviewed publication.

Local content check: `node scripts/test-website-guide.mjs` from the Jupiter root.
PDF reproduction uses Python `markdown` and `pypdf`, installed Shabnam assets,
the product logo, Playwright and Microsoft Edge:

1. Read the PDF skill and execute its required artifact-operation marker once
   immediately before starting a new create/edit authoring operation.
2. Run `python scripts/render-website-guide.py`.
3. Run `node scripts/render-website-guide.mjs`.
4. Render ALL pages with Poppler and inspect, including Persian/Latin mixed text,
   page boundaries, fonts and links. Copy the verified `output/pdf/` artifact to
   this overlay's public PDF path only after review.

The PDF is NOT generated by printing only the selected web tab: it includes all
three audience paths, all Help/FAQ content and the optional monitoring chapter.
No credentials, private URLs, customer screenshots or fixed commercial promises
belong in this material. Actual publication/verification/rollback evidence is in
`docs/WEBSITE_GUIDE_REFRESH_20261025.md`.
