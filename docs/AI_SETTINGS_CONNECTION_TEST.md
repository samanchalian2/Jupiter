# آزمون اتصال تنظیمات AI

مدیر پلتفرم پس از انتخاب سازمان و ذخیرهٔ تنظیمات AI، می‌تواند از دکمهٔ
«آزمون اتصال» استفاده کند. آزمون یک درخواست بسیار کوتاه و غیرحساس به
`/chat/completions` می‌فرستد و فقط این سه جزء ذخیره‌شده را بررسی می‌کند:

- Base URL
- API key
- مدل تحلیل

کلید API، پاسخ خام ارائه‌دهنده و محتوای هیچ تیکتی در رابط، پاسخ API، لاگ یا
ردپای ممیزی نمایش داده یا ثبت نمی‌شود. نتیجهٔ ممیزی تنها شامل موفق/ناموفق و
دستهٔ تشخیصی است.

نتیجه‌های عملیاتی:

- «اتصال با موفقیت برقرار شد»: سه جزء فوق قابل استفاده‌اند.
- «کلید API پذیرفته نشد»: کلید همان پروژهٔ API را جایگزین و ذخیره کنید.
- «صورت‌حساب یا اعتبار API فعال نیست»: Billing یا Usage Limit پروژه را فعال
  یا افزایش دهید. اشتراک ChatGPT جای API billing را نمی‌گیرد.
- «محدودیت موقت»: کمی بعد دوباره آزمون را اجرا کنید.
- «Base URL یا مدل در دسترس نیست»: آدرس، نام مدل و دسترسی پروژه را بررسی
  کنید.

این آزمون تیکت یا intake session ایجاد نمی‌کند و جای آزمون نهایی جریان متن و
صدا را نمی‌گیرد.

## شواهد محلی — ۲۲ مرداد ۱۴۰۵

تنظیم ذخیره‌شدهٔ Jupiter Demo Organization با Base URL سازگار با OpenAI از
GapGPT و مدل تحلیل `gpt-4o` در endpoint داخلی آزمون اتصال موفق بود. سپس همان
تنظیم با یک درخواست غیرحساس `ticket-intake.v1` نیز بررسی شد و خروجی ساختاریافتهٔ
معتبر شامل عنوان و اولویت NORMAL بازگشت. آزمون صوت نیازمند اطمینان جداگانه از
در دسترس بودن مدل تبدیل صوت در فهرست ارائه‌دهنده است.
