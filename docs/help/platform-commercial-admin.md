# مدیریت خدمات تجاری و ظاهر پلتفرم

فقط مدیر پلتفرم می‌تواند قراردادها، سهمیه‌ها، بسته‌ها، سیاست Jupiter Assist و ظاهر سراسری را مدیریت کند. این اختیارات به مدیر سازمان منتقل نمی‌شود.

ظاهر پلتفرم فقط از presetهای تأییدشده رنگ، تراکم و گوشه‌ها و یک مسیر داخلی لوگو استفاده می‌کند. کد CSS، JavaScript و نشانی خارجی برای لوگو قابل ثبت نیست.
