# شروع کار با Jupiter

برای ثبت درخواست، شرح مسئله را روشن و کامل وارد کنید، سپس دسته‌بندی و اولویت را بازبینی کنید. پس از ثبت، وضعیت و پاسخ‌ها از همان تیکت قابل پیگیری هستند.

اگر پاسخ پیشنهادی هوشمند نمایش داده شد، پیش از ثبت نهایی آن را بازبینی یا ویرایش کنید.
