# رنگ اصلی و ظاهر Platform و سازمان

رنگ پایهٔ Jupiter در Light Theme، `#315399` است. Platform Admin می‌تواند presetهای کنترل‌شده، رنگ اصلی سفارشی، تراکم، radius و لوگوی داخلی را مدیریت کند. رنگ سفارشی فقط خانوادهٔ رنگ اصلی را تغییر می‌دهد؛ رنگ‌های موفقیت، هشدار، خطا و عملیات مخرب مستقل می‌مانند.

رنگ سفارشی فقط با قالب `#RRGGBB` پذیرفته می‌شود؛ برای نمونه `#315399` یا `#1A6F55`. کد CSS، `rgb(...)`، نام رنگ، متغیر، URL، gradient یا محتوای دلخواه قابل ذخیره نیست. قبل از ذخیره، پیش‌نمایش دکمه، پیوند، ناوبری انتخاب‌شده، focus و نمونهٔ رنگ‌های معنایی را بررسی کنید. سرور نیز کنتراست را دوباره بررسی می‌کند و برای متن روی دکمه، foreground سفید یا تیره را به‌صورت deterministic انتخاب می‌کند.

اگر سازمان رنگ سفارشی نداشته باشد، رنگ مؤثر Platform را ارث می‌برد. Platformهایی که رنگ سفارشی یا preset غیرپیش‌فرض ندارند، رنگ `#315399` را ارائه می‌کنند. «بازگشت به پیش‌فرض» در سازمان فقط override سازمان را حذف می‌کند؛ در Platform، رنگ را به preset ژوپیتر و `#315399` بازمی‌گرداند. تراکم، radius و لوگو با reset رنگ تغییر نمی‌کنند.

سازمان می‌تواند رنگ اصلی و لوگوی خود را در محدودهٔ مجاز نمایش دهد، اما نمی‌تواند رنگ‌های معنایی، layout یا ناوبری پلتفرم را بازتعریف کند. تغییر ظاهر باید پیش‌نمایش و خوانایی فارسی و RTL را حفظ کند.

Appearance مسیر تغییر نقش، دسترسی، دادهٔ سازمان یا قرارداد تجاری نیست. برای مشکل بصری پایدار، تنظیم را به حالت مناسب بازگردانید و با Platform Admin پیگیری کنید.
