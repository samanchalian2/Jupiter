# ظاهر Platform و سازمان

Platform Admin می‌تواند فقط presetهای کنترل‌شدهٔ برند، تراکم، radius و لوگوی داخلی را مدیریت کند. این کنترل‌ها semantic color، contrast و ساختار تجربه را از بین نمی‌برند و برای حفظ یکپارچگی محصول محدود هستند.

سازمان می‌تواند لوگوی خود را در محدودهٔ مجاز نمایش دهد، اما نمی‌تواند رنگ‌های معنایی، layout یا ناوبری پلتفرم را بازتعریف کند. تغییر ظاهر باید پیش‌نمایش و خوانایی فارسی و RTL را حفظ کند.

Appearance مسیر تغییر نقش، دسترسی، دادهٔ سازمان یا قرارداد تجاری نیست. برای مشکل بصری پایدار، تنظیم را به حالت مناسب بازگردانید و با Platform Admin پیگیری کنید.
