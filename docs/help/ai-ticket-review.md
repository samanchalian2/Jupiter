# دستیار هوشمند و تیکت

«Smart Intake» می‌تواند متن یا گفت‌وگوی اولیه را برای پیشنهاد عنوان، شرح، دسته‌بندی و مسئلهٔ دوم تحلیل کند. «Ticket Review» پیش از ثبت، متن تیکت را برای کامل‌ترشدن بررسی می‌کند. هر تحلیل intake یک اقدام هوشمند است؛ پیشنهادهای درون همان تحلیل، تلاش مجدد و اصلاح فنی خروجی، مصرف جداگانه ندارند.

## کنترل کاربر و ثبت دستی

پیشنهاد هوشمند جای تصمیم شما را نمی‌گیرد. متن را بازبینی و ویرایش کنید و تیکت فقط با تأیید و ثبت صریح شما ایجاد می‌شود. اگر سرویس برای سازمان فعال نباشد، اشتراک مجاز نباشد یا سهمیه تمام شده باشد، پیام روشن نمایش داده می‌شود و ویرایش و ثبت دستی همیشه برقرار است.

تحلیل صوتِ مستقلِ پیوست فعلاً واحد تجاری جداگانه ندارد. متن تیکت، prompt، فایل و secret در گزارش مصرف تجاری ذخیره نمی‌شود.
