# پیکربندی تیکت‌ها

Catalog مشخص می‌کند کاربران برای چه خدمت‌هایی تیکت ثبت کنند. دسته‌ها را روشن، کوتاه و متناسب با خدمات واقعی سازمان نگه دارید. هر دسته باید مسیر رسیدگی قابل‌فهمی داشته باشد.

تیم‌ها مسئول رسیدگی هستند. اعضا و نقش‌های تیم را پیش از استفاده عملیاتی بررسی کنید تا تیکت‌ها به گروه درست برسند. تنظیمات سازمانی، دسته‌بندی و تیم‌ها ممکن است بر آمادگی Wizard اثر بگذارند؛ پس تغییرهای مهم را با هدف Go-Live بازبینی کنید.

برای زمان‌بندی پاسخ و تعطیلات از تنظیمات SLA و تقویم کاری استفاده کنید؛ آن‌ها در راهنمای جداگانه توضیح داده شده‌اند.
