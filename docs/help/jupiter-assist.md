# Jupiter Assist

اگر سازمان شما سرویس Jupiter Assist فعال دارد، می‌توانید از صفحهٔ تیکت درخواست کمک از تیم Jupiter را ثبت کنید. این درخواست، تیکت اصلی و وضعیت آن را تغییر نمی‌دهد و تیم Jupiter فقط در محدودهٔ دسترسی تأییدشده کار می‌کند.

ظرفیت Assist یک «پروندهٔ پذیرفته‌شده» است، نه تعداد پیام‌ها یا درخواست‌ها. ثبت درخواست، بررسی، صف و assignment ظرفیت مصرف نمی‌کند. فقط وقتی پرونده پذیرفته شود، دقیقاً یک واحد از یک بستهٔ فعال مصرف می‌شود. تلاش دوباره یا پذیرش هم‌زمان واحد دوم ایجاد نمی‌کند.

بستهٔ منقضی یا تعلیق‌شده برای پذیرش پروندهٔ جدید مصرف نمی‌شود، اما پرونده‌ای که پیش‌تر پذیرفته شده است طبق دسترسی و چرخهٔ عمر خودش ادامه می‌یابد. داشبورد مالک فقط جمع ظرفیت، مصرف، باقی‌مانده و وضعیت را نمایش می‌دهد.
