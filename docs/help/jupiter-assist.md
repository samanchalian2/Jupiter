# درخواست کمک از تیم Jupiter

اگر سازمان شما سرویس پشتیبانی Jupiter را فعال کرده باشد، می‌توانید از صفحه تیکت درخواست کمک ارسال کنید. این درخواست چرخه‌ای مستقل از وضعیت تیکت دارد.

کارشناس Jupiter فقط در محدوده و بازه زمانی مجاز به اطلاعات تیکت دسترسی دارد. تیکت‌های محدودشده به مجوز مشخص نیاز دارند.
