# راهنمای اتصال فهرست سازمانی

اتصال فهرست سازمانی از طریق یک سرویس ویندوزی با ارتباط خروجی HTTPS انجام می‌شود. رمزهای Active Directory به Jupiter ارسال یا در فضای ابری ذخیره نمی‌شوند.

پیش از اعمال تغییرات، نتیجه همگام‌سازی را بررسی کنید. همگام‌سازی نقش مدیر سازمان یا مالک سازمان را ایجاد یا تغییر نمی‌دهد.
